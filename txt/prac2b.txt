Practical No: 2B
Title: DFS for Missionaries and Cannibals Problem

Aim:
To implement the Depth First Search (DFS) algorithm to solve the Missionaries and Cannibals Problem and find a valid sequence of moves from the initial state to the goal state.

Problem Statement:
Three missionaries and three cannibals are on the left bank of a river. They must all cross to the right bank using a boat that holds at most two people. At no point on either bank may cannibals outnumber missionaries (unless missionaries count is 0), otherwise the cannibals will eat the missionaries. Determine a safe transition sequence from initial state (3, 3, 1) to goal state (0, 0, 0) using Depth First Search.

Objectives:
- Understand uninformed search techniques applied to classic AI puzzles.
- Implement Depth First Search (DFS) using recursion and backtracking.
- Define valid state representations and safety constraint functions.
- Avoid infinite cycles by tracking previously visited states.

State Representation:
A tuple (M, C, B) represents:
- M: Number of missionaries on left bank (0 to 3)
- C: Number of cannibals on left bank (0 to 3)
- B: Boat position (1 = left bank, 0 = right bank)

Valid Moves:
Boat can carry: (2, 0), (0, 2), (1, 1), (1, 0), (0, 1) missionaries and cannibals.

Safety Condition:
For both left and right banks:
If M > 0, then M must be >= C.

Expected Output:
Valid sequence of 12 states from (3, 3, 1) down to (0, 0, 0):
(3, 3, 1) -> (3, 1, 0) -> (3, 2, 1) -> (3, 0, 0) -> (3, 1, 1) -> (1, 1, 0) ->
(2, 2, 1) -> (0, 2, 0) -> (0, 3, 1) -> (0, 1, 0) -> (1, 1, 1) -> (0, 0, 0)
